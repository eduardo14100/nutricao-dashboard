# 🥗 Painel de Acompanhamento Nutricional & Projeção EWMA

Painel web responsivo e interativo para acompanhamento de protocolo nutricional (cutting 2026):
- 🌮 Tabela TACO Oficial (603 alimentos cadastrados) com calculadora de trocas equivalentes;
- 📈 Projeção de tendência de peso suavizada via modelo EWMA (α=0.15) do `nutrition-mcp`;
- 🎛️ Simulador em tempo real de déficit calórico diário;
- 🔒 Tela de bloqueio e privacidade com PIN local via Web Crypto SHA-256;
- 📄 Plano completo disponível em PDF (`plano_nutricional.pdf`).
